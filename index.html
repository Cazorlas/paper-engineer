Paperclip

A private publishing tool for the YouTube channel Kỹ sư giấy (@paper.engineer).

What it is

Paperclip is a command-line tool that runs only on the channel owner's own computer. It turns a public GitHub repository into a short Vietnamese explainer video (vertical, under 3 minutes). It is not a public service, has no website login and no other users.

How it uses the YouTube Data API

  • The channel owner reviews and approves every script and every finished video before upload.
  • The tool then calls videos.insert (scope youtube.upload) to upload that one approved video to the owner's own channel, with its title, description and hashtags, declared as not made for kids and as containing synthetic media (the narration is a synthetic voice).
  • With youtube.readonly it reads only the owner's own channel name, to confirm the sign-in is the right channel, and the status of the videos it uploaded.
  • It uploads 1 to 3 videos per day. It does not access any other user's channel or data.

Paperclip uses YouTube API Services. By using it the channel owner agrees to the YouTube Terms of Service.
