Privacy Policy

Paperclip, the publishing tool of the YouTube channel Kỹ sư giấy (@paper.engineer). Effective 5 October 2026.

Who uses it

Paperclip is used only by the owner of the channel Kỹ sư giấy, on their own computer. It has no other users and no public sign-up.

What data it accesses

  • Through YouTube API Services, with the owner's consent given in Google's sign-in screen: permission to upload videos to the owner's channel (youtube.upload), and read access (youtube.readonly) used only to read the owner's own channel name and the status of the videos the tool uploaded.
  • Public information about GitHub repositories (name, description, star counts, README), which is the subject of each video.

It does not access, collect or process data about any other YouTube user, viewer or channel.

How data is stored

  • The OAuth tokens Google issues are stored only in a file on the owner's computer. They are never sent to any server other than Google's, never shared and never published.
  • The tool keeps a small local record of each upload (video id, link, privacy status, upload time) on the same computer.
  • No data is sold, shared with third parties or used for advertising.

Google and YouTube

Paperclip uses YouTube API Services. By using it, the channel owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

The channel owner can revoke Paperclip's access at any time at Google Account → Security → Third-party connections. The owner can also delete the local token file; nothing else holds the data.

Contact

Questions about this policy: open an issue at github.com/Cazorlas/paper-engineer.
